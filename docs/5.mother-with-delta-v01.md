# mother-with-delta-v01 (delta-only lineage)

Intra-family parent -> child inference **without kurtosis**. Direction is decided only from
the weight difference (`delta = W_b - W_a`) and an SVD of the two matrices, per layer:

- **Delta energy**: `||U_k^T · delta||^2` using the top-10 left singular vectors of each model.
- **Spectral concentration**: `sigma_max / sum(sigma)`.
- If the energy ratio is > 1.01 the layer votes in **additive** mode (trust delta), otherwise in
  **subtractive** mode (trust spectrum). Votes give the verdict and the confidence.

Layers used: 2D and 4D tensors (4D are flattened), excluding `norm`, `embed`, `lora`, `bias`,
`time`, Q and K projections (and V projections with `exclude_value=True`).

## API

```python
from src.mother_algorithm.delta_lineage import process_lineage_graph

out_graph, stats = process_lineage_graph(input_graph, penalty=0.5, exclude_value=False)
```

`input_graph` is an `nx.DiGraph`. Each node carries `path` (or `file_path`): a single
`.safetensors` / `.bin` / `.ckpt` / `.pt` / `.pth` file, or a **sharded directory** (shards are merged).
Input edges, if present, select the pairs to test; otherwise all node pairs are tested.

For every tested pair both edges are inserted:

| Edge | `weight` | `is_correct_direction` |
|---|---|---|
| predicted parent -> child | `base_confidence` | `True` |
| child -> parent | `base_confidence + penalty` | `False` |

`base_confidence = max(0.001, 1 - confidence/100)` is a cost (lower = more confident), so a minimum
spanning arborescence prefers confident edges. The raw confidence (%) is kept in the edge attribute `confidence`.

Diagnostic logging (logger `delta_lineage`, level INFO): per pair `process_time` (algebra only)
and `valid_layers`. Both are also stored per edge and aggregated in `stats`.

## Running the variant in the backend

```python
from src.mother_algorithm.tree_builder import MoTHerTreeBuilder, TreeBuildingMethod

builder = MoTHerTreeBuilder(method=TreeBuildingMethod.MOTHER_WITH_DELTA_V01,
                            delta_penalty=0.5, exclude_value=False)
tree, confidence, _ = builder.build_family_tree(family_id, models)
```

`ModelManagementSystem(tree_method=TreeBuildingMethod.MOTHER_WITH_DELTA_V01)` is already supported,
because the method is passed through to `MoTHerTreeBuilder`. The default method stays `MOTHER`.

## Benchmark

```bash
python scripts/benchmark_lineage.py \
    --graph graph.json --ground-truth ground_truth.json \
    --models-dir /data/models --penalty 0.5 --output-dir results/ -v
```

Arguments: `--graph`, `--ground-truth` (required); `--tree-id`, `--models-dir`, `--penalty`
(default 0.5), `--exclude-value`, `--output-dir`, `-v`.

`graph.json`:

```json
{"nodes": [{"id": "base", "path": "base.safetensors"},
           {"id": "ft1",  "path": "ft1_sharded_dir"}],
 "edges": [{"source": "base", "target": "ft1"}]}
```

`ground_truth.json`: `{"edges": [["base", "ft1"]]}` or the `freccia_del_tempo` format
(`root`, `d1`, `d2`, ...; with `TREES` use `--tree-id`).

Output (stdout; with `--output-dir` also `tables.md`, `tables.tex`, `stats.json`):

1. **Comparative Performance Metrics**: accuracy vs ground truth, mean confidence, mean pair
   processing time, total execution time, mean layers used per model.
2. **Structural & Directional Analysis**: correct directed edges, penalized reverse edges,
   additive/subtractive ratio, penalty impact on weight.

Notes: accuracy is computed by the script by comparing predicted `parent -> child` edges with the
ground truth; total execution time includes weight loading. The LaTeX tables use `booktabs`
(`\usepackage{booktabs}`) and `graphicx`.
